# Guarded-Byesian-Chain-Ladder

This repository contains the official reference implementation for Guarded Bayesian Chain-Ladder (GBCL) reserving. Its primary purpose is to provide a compact, reproducible environment for detecting uncertain calendar-year shocks in loss reserving data while applying a structural "guard" to stabilize reported reserves. The codebase packages the core statistical engine, data acquisition scripts for historical CAS Schedule P triangles, group-clustered validation tools, and a validation test suite into a single, clean workspace.
